# Benchmark 与指标口径

数据集：`shopdesk-jade-fictional-v1`。共 32 个测试轮次，包含单轮与多轮场景。资料为项目构造的翡翠单件档案、店铺政策和演示订单。

## 最新本地实测

日期：2026-10-19，Windows / Python 3.14。Embedding=hash，Rerank=local。运行入口 `python -m shopdesk evaluate`。

| 指标 | 完整链路 |
|---|---:|
| 期望事实命中 | 100.0% |
| 意图准确率 | 100.0% |
| 路由准确率 | 100.0% |
| 商品实体准确率 | 100.0% |
| 检索 Recall@3 | 100.0% |
| 链路处理 P50 | 33.45 ms |
| 链路处理 P95 | 37.66 ms |

基线采用原始 Query、统一窗口分块与混合检索，来源 Recall@3 为 97.7%；上下文事实覆盖率为 100.0%，检索 P50 为 11.48 ms。基线仅测量检索输出，完整链路测量生成后的回答，两类耗时分别统计。

## 计算方法

- 答案事实命中：当前轮所有预先标注的关键字符串均出现在最终回答中。
- 意图、路由和实体：与固定标注逐轮比较；实体只在标注指定的场景计算。
- Recall@3：前三个重排候选的独立文档 ID，与当前轮相关文档集合的交集数量除以相关文档数量。只对有知识来源标注的轮次计算。
- P50/P95：Service 内本轮实际执行耗时；包含图执行、检索、生成及记忆提交，不包含浏览器网络等待。
- 基线上下文覆盖：前三个原始召回片段是否同时包含期望事实。

## 复现与扩展

评测使用独立临时数据目录，保持工作台运营知识与会话不变。每个场景保留原始问题、回答、状态比较、来源比较和失败标签。修改 `src/shopdesk/assets/data/benchmark.json` 可以扩展不同翡翠档案与客户表达。

真实业务评估可补充人工标注的事实一致性、问题解决率、转人工恰当性和客户满意度，分别记录模型、Prompt、Embedding、Rerank 与知识版本。内置数据集的覆盖范围用于项目回归，业务指标由实际客服使用记录测量。

完整机器报告见 [examples/benchmark-result.json](../examples/benchmark-result.json)。

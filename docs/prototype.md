# 交互原型与信息架构

项目中的工作台由 FastAPI 提供页面与 API，同源 JS 驱动交互，可直接作为可运行原型演示。

## 信息架构

```text
ShopDesk · 翡翠专营店
├─ 智能问答
│  ├─ 最近会话 / 新建会话
│  ├─ 单件咨询 / 多轮追问 / 转人工
│  └─ 意图 / Query / 链路 / 引用 / 重排详情
├─ 知识库
│  ├─ 商品档案 / FAQ / 售后 SOP
│  ├─ 搜索 / 类型筛选 / 编辑 / 启停 / 删除
│  └─ 手动重建索引
├─ 人工转接
│  ├─ 上下文摘要
│  └─ 接入处理 / 标记解决
└─ 评测中心
   ├─ 运行 Benchmark / 基线对照
   └─ 客户负向反馈
```

## 视觉与布局

以玉绿色、暖白色和浅灰线条组织工作台。桌面为导航、会话、聊天和证据的分栏布局；窄屏收起会话列表，证据区移到聊天下方。正文与来源可分别滚动，输入框始终位于聊天区底部。

## 关键交互

1. 快捷问题填写真实问答请求，SSE 推送节点进度，完成后显示回答和引用。
2. 查看依据可切换到该条回答的 Query、节点耗时和来源。
3. 编辑知识弹出表单，包含标题、类型、适用商品、正文和启用开关。
4. 工单接入后进入处理中，解决时必须填写说明。
5. 管理口令保留在当前浏览器 sessionStorage，通过 X-Admin-Token 请求管理接口。

## 空态、错误与恢复

未提问时显示翡翠快捷问题；无工单时说明触发条件；无评测时提供运行入口。网络或模型执行失败以提示反馈，本轮保留为失败请求，新请求使用新的 ID。完成请求的重复提交返回缓存答案。

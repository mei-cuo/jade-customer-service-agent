## 可用于简历的表述

项目名称：翡翠电商 AI 智能客服平台（个人项目）。项目时间按实际投入日期填写。

- 设计并实现 LangGraph 问答链路，串联意图识别、上下文 Query 改写、BM25 与 Qdrant 混合召回、RRF、Rerank 及带引用的回答生成。
- 为单件商品档案、FAQ 与售后 SOP 设计差异化 Chunk 策略，结合父段上下文、滑动窗口和 Overlap 管理规格、条件与流程信息。
- 实现 SQLite 多轮 Memory、请求幂等、知识版本同步与人工转接；围绕商品指代、运费追问和规格遗漏建立 Benchmark 与 Bad Case 回归。
- 完成 PRD、可运行工作台和 API，覆盖知识库管理、智能问答、人工工单及评测中心，并提供容器与 CI 配置。

若填写量化结果，应注明数据集、用例数量和指标口径，使用实际运行的 Benchmark 报告；业务转化和人工提效需在真实使用中测量。
